# 내 기획 프롬프트 작성 기준

프로젝트의 실제 메모와 판단에서 재사용할 절차를 만드는 방법입니다. 무료 대화창이나 메모 앱으로 작성하고, 사용한 모델과 실제 결과는 실행한 뒤 기록합니다.

## 1. 조건과 이유

상황 / 판단과 이유 / 적용하지 않을 조건 / 다음 확인과 재검토 조건을 먼저 적습니다. 사실과 가설을 구분하고 회사 필수 기준을 우선합니다.

## 2. 입력 준비

실제 메모와 내 확정 선택을 전문으로 전달합니다. 파일 도구는 작업 폴더와 파일을 지정하고, 대화창은 본문을 첨부하거나 붙입니다. 이름만 적어서 읽었다고 가정하지 않습니다.

## 3. 두 메타프롬프트

실제 값으로 바꾸고 한 요청씩 보냅니다. 질문에 내가 답하고 확정한 뒤 지시를 만듭니다.

입력 양식

```text
검토할 결정: [내 메모의 실제 결정·이유·근거·미정]. 이 선택을 바꿀 빈칸만 하나씩 최대 두 번 질문하세요. 제 답을 기다리고 근거와 가정을 나누세요. 충분하면 멈추며 제 확정 전에는 범위·기능·성과를 결정하지 마세요.
```

값을 채운 홈화면 예시, 같은 선택일 때만 사용

```text
홈화면은 새 작업 시작에 집중하고 범용 대화는 제외, 개인화는 이력·노출 기준이 없어 보류했습니다. 이전 작업 이어가기가 필수인지 미정입니다. 이 선택을 바꿀 빈칸만 하나씩 최대 두 번 질문하고 제 답을 기다리세요. 기능이나 성과는 아직 확정하지 마세요.
```

입력 양식

```text
제가 확정한 판단: [고친 기준표 전체]. 이를 재사용할 AI 작업 지시로 바꾸세요. 적용·비적용 조건과 이유, 자료·허용 도구·중단·사람 확인·결과 확인을 담아 읽기→제안→사람 확정→초안→검토로 나누세요. 각 요청은 200자 이내로 쓰고 미정은 채우지 마세요.
```

값을 채운 홈화면 예시, 같은 선택일 때만 사용

```text
새 작업 시작 우선, 이어하기는 이력·복귀 화면 확인 전 동작 보류로 확정했습니다. 이를 읽기→제안→사람 확정→초안→검토의 AI 지시로 바꾸세요. 적용·비적용 조건과 이유, 자료·허용 도구·중단·사람 확인·결과 확인을 담고 각 요청은 200자 이내로 쓰세요.
```

## 4. 내기획프롬프트.md

언제 쓸지 / 언제 다르게 할지 / 이유 / 읽힐 자료 / 읽기→제안→사람 확정→초안→검토 / 실패·중단·사람 확인 조건을 저장합니다. 단계별 요청은200자 이내로 쓰고 다른 업무에 맞는 실제 값으로 바꿉니다.

## 5. 반례와 실제 결과

근거 없는 고객 요구, 이전 보류와 충돌하는 추가 요청, 참조자료 읽기 실패를 하나씩 넣어 확인합니다. 기대와 실제 응답을 구분합니다. 모델 미실시는 미실시로 남기고, 수용한 수정만 반영해 같은 입력으로 다시 확인합니다.

## 6. 문서의 책임

customer.md는 고객 근거, prd.md는 확정 요구·품질, architecture.md는 실행 책임, progress.md는 실제 선택·결과를 보존합니다. 같은 프로젝트의 관련 절만 갱신하고 기존 기록은 덮지 않습니다. A/B의 고객 사실을 합치지 않습니다.

## 7. 새 대화

최종 내기획프롬프트.md 전체와 이번 업무 입력을 전달하고 실제로 재사용합니다. 이전 특정 기능·가격·가설을 새 사실로 옮기지 않습니다.

## hplan

https://github.com/kimsanguine/hplan

경험의 적용 조건과 지시 변환은pm-engine, 도구와실패/사람확인은agent-setup, 이전제외와결정은exclusions/decision-log, 승인된인계는handoff에서이어볼수있습니다. 이Markdown과hplan의JSONL/checkpoint는별도형식이며설치·설정없이실행차단이생기는것은아닙니다.


## 실제 초안과 반례 기록 위치

제공 A/B는 폴더를 나누고 각 prd.md의 검토 중 초안 절에 실제 결과를, progress.md의 프롬프트 검토 절에 입력·기대·실제·내 결정을 남깁니다. 채택한 요구만 PRD 확정 절에 반영하고 기존 기록을 보존합니다.

자료 부재 반례는 파일 접근 도구가 없는 일반 대화창의 별도 새 대화에 최종 지시와 업무 입력만 전달합니다. customer.md 원문으로 요구를 검토하라고 요청하되 그 전문은 첨부하지 않습니다. 자료를 요청하고 의존 작업을 보류하는지 실제로 봅니다. B에서도 반례 확인과 내 수용·기각 뒤 최종 기준을 재저장합니다.
