# 영상 현지화, 결정과 실제 결과

실제 회사 기록과 별개의 연습 입력에 사람이 선택을 남기는 모습을 보여줍니다. 아래 선택 이유는 채운 예시이며 독자가 실제로 한 결정이나 실행 결과가 아닙니다. 기존 프로젝트의 상태를 이 예시로 초기화하지 않습니다.

## 결정 DEC-001

- date: 2026-11-10
- owner: 프로젝트 담당자, 실제 승인자는 별도 확인 필요
- review: 2026-11-17
- 질문: 전체 영상 재생성 대신 작업자가 선택한 한 구간의 재시도안을 검토할 것인가?
- 사용자 결과와 사업 목표: prd.md의 목표와 측정 참조. 원본과 다른 구간을 유지하고 감당할 생성 범위를 파악한다.
- 제약: 코드 미구현. 실제 인터뷰와 시험 결과 없음. 단가, 비용 한도, 재시도 상한 수치와 실제 생성 권한 미확인.
- 근거: customer.md의 INPUT-01은 연습 상황과 제약을 제공한다. 고객 수요나 효과의 증거는 없다.
- 가장 약한 가정: 한 구간 재시도안 검토가 수동 편집보다 작업자에게 도움이 된다.
- 반대 근거: 실제 자료를 찾지 못함. 수동 편집만으로 충분한 최근 사건을 확인하면 선택이 달라질 수 있다.
- 선택지: 수동 편집 유지, 전체 영상 재생성, 선택 구간 재시도안 검토, 기존 결과 유지, 추가 확인과 보류.
- 사람의 선택: 선택 구간 재시도안의 문서와 수동 흐름 검토를 진행하고, 실제 생성과 전체 개발은 보류한다.
- 이유와 감수한 것: 원본과 범위를 지킬 절차를 먼저 비교할 수 있다. 이번에는 실제 품질과 비용, 수요에 대한 결론을 미룬다. 구간 방식이 항상 싸거나 낫다고 단정하지 않는다.
- 의식적으로 포기한 것: 전체 재생성과 자동 게시. 변경 영향과 검토 부담, 실행 권한이 커지므로 이번에 다루지 않는다.
- 다시 판단할 조건: 단가와 실제 처리량, 비용 한도와 재시도 상한, 자료 권한과 승인자를 확인하고 실제 최근 사건 자료가 생기면 범위를 다시 정한다.
- 허용 행동: 프로젝트 담당자가 INPUT-01로 구간 선택, 원본과 후보 분리, 사람 채택과 반려를 수동 검토한다.
- 금지와 보류: 구간 밖 변경과 자동 게시 금지. Q3 확인 전 실제 모델 생성과 자료 전송 보류.
- 품질과 복구: prd.md의 Q1, Q2, Q3, architecture.md의 오류와 복구 참조.
- 다음 확인: 실제 편집자의 최근 처리 사건을 물을 접근 권한과 일정 확인. 공급자 단가와 한도를 확인할 담당자 찾기.
- review 선택 조건: 수동 흐름에서 원본과 후보, 변경 범위를 구별할 수 있으면 검토 유지. 혼동되면 입력과 절차 수정. 승인과 한도가 계속 미확인이면 생성 보류 유지. 수동 대안이 충분하다는 실제 근거가 있으면 범위 축소 또는 중단/보류 비교. 자료가 부족하면 추가 관찰을 고르고 확인 대상, 담당, 날짜와 그동안 보류할 실행 범위를 정한다.
