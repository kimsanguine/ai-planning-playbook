# 영상 현지화, 고객과 문제

실제 회사 기록과 별개의 연습 입력입니다. 인터뷰와 실제 사용 관찰은 없습니다. 이 파일의 상태를 이미 실행한 자기 프로젝트에 복사하지 말고 필요한 절만 병합합니다.

## 결정 연결

- 관련 결정: progress.md의 DEC-001
- 목표와 기준: prd.md의 목표와 측정, 품질 기준
- 연습 기준일: 2026-11-10

## 역할과 문제

| 역할 | 상황과 기대 | 확인 상태 |
|---|---|---|
| 사용자, 영상 편집자 | 길이가 맞지 않는 구간을 고치면서 다른 구간과 원본을 유지하고 싶다는 조건 | INPUT-01에 주어진 연습 조건, 실제 고객 확인 없음 |
| 구매자 | 도입과 생성 비용을 결정하는 역할 | 실제 역할과 지불 의향 미확인 |
| 운영자, 작업 관리자 | 범위와 승인, 복구를 확인하는 역할을 둠 | 연습 설계, 실제 운영 인터뷰 없음 |

문제 가설: 더빙 길이가 맞지 않는 한 구간 때문에 전체를 다시 작업해야 한다면 불필요한 검토 부담이 생길 수 있다. 실제 부담과 발생 빈도는 미확인이다.

## 최근 사건과 자료

| 자료 ID | 종류 | 내용 | 한계 |
|---|---|---|---|
| INPUT-01 | 독립 연습 입력 | 번역과 더빙을 마친 영상에서 한 구간의 길이가 맞지 않는다. 작업자가 시작과 끝을 선택해 재시도안을 검토한다. 원본 보존, 구간 밖 변경 금지, 자동 게시 없음. | 실제 인터뷰, 사용 로그, 시험 결과가 아님. 단가와 재시도 상한 수치도 없음. |

## 현재 대안

| 대안 | 얻으려는 결과 | 비교할 부담 | 확인 상태 |
|---|---|---|---|
| 기존 편집 도구로 수동 수정 | 필요한 구간을 직접 조정 | 실제 수정 시간과 품질 | 실제 관찰 없음 |
| 전체 영상 재생성 | 새 결과를 받아 검토 | 다른 구간 변경, 전체 검토와 비용 | 실제 비용과 품질 미확인 |
| 작업자가 고른 한 구간 재시도안 검토 | 다른 구간을 유지한 채 후보 검토 | 구간 선택 오류, 후보 품질과 재시도 비용 | 지금 비교할 안, 실제 생성 보류 |
| 기존 결과 유지 | 추가 생성 없이 현재 상태 유지 | 길이 불일치가 남을 영향 | 고객이 감내할지 미확인 |

경쟁 제품의 실제 기능과 가격은 조사하지 않았다. 기존 편집 도구가 충분한지 먼저 확인할 대상이다.

## 가정과 반대 근거

- 가장 약한 가정: 한 구간 재시도안 검토가 수동 편집보다 작업자에게 도움이 된다.
- 지지 자료: INPUT-01은 연습 상황을 줄 뿐, 수요나 효과를 지지하는 고객 증거는 없다.
- 반대 근거: 실제 자료를 찾지 못했다. 수동 수정만으로 충분히 끝내는 최근 사건을 관찰하면 선택을 다시 볼 수 있다.
- 다음 확인: 마지막으로 길이 불일치를 발견한 뒤 어떤 순서로 처리했는지 실제 편집자에게 묻는다.
- 확인 담당과 날짜: 프로젝트 담당자, 2026-11-17 첫 리뷰에서 접근 가능 여부 확인.

선택 이유는 progress.md의 DEC-001에 있다. 원본과 구간의 조건은 prd.md의 Q1, Q2, 실행 전 조건은 Q3가 정본이다.
