# 영상 현지화, 목표와 제품 기준

실제 회사 기록과 별개의 연습 설계입니다. 코드 미구현, 실제 인터뷰와 시험 결과 없음. 목표와 품질 기준은 이 파일이 정본이며 변경은 progress.md의 새 결정으로 사람이 확정합니다.

## 목표와 측정

- 관련 결정: progress.md의 DEC-001
- 문제 가설과 입력: customer.md의 역할과 문제, INPUT-01
- 사용자 결과: 작업자가 선택 구간의 재시도안을 검토하면서 원본과 다른 구간을 지킨다.
- 사업 또는 운영 목표: 생성의 비용과 검토 부담을 파악한 뒤 감당할 범위를 정한다. 매출, 절감 효과는 미확인이다.
- 관찰 단위: 작업 한 건의 선택 구간, 수정 이유, 검토와 재작업 과정. 실제 생성이 허용되면 처리량, 재시도와 대기, 비용도 기록한다.
- 기준선과 목표값: 미확인. 먼저 현재 수동 처리의 관찰 가능성과 수집 권한을 확인한다.
- 측정 방법과 담당: 프로젝트 담당자가 허용된 수동 흐름을 따라가며 기록하고, 실제 고객 접근 여부를 2026-11-17에 검토한다.
- 감내할 선택: 이번에는 실제 품질과 비용의 결론을 미루고 수동 검토를 진행한다. 원본 손실과 구간 밖 변경은 허용하지 않는다.

## 대안과 범위

| 방법 | 적용 | 이번 판단 |
|---|---|---|
| 제거 | 불필요한 전체 재작업을 없앨 가능성 | 고객의 실제 처리 확인 전 효과 단정 보류 |
| 표준화 | 시작과 끝, 수정 이유를 입력 항목으로 정함 | 수동 흐름에서 검토 |
| 규칙 자동화 | 범위와 권한, 상한 확인 | 설계에 포함, 코드 미구현 |
| AI 증강 | 번역과 더빙 후보를 만드는 역할 | 실제 생성은 Q3 충족 전 보류 |

- 포함: 작업자가 한 구간을 선택, 재시도안의 수동 검토, 원본과 후보 분리 설계, 사람이 후보를 채택하거나 반려하는 흐름.
- 제외: 전체 영상 재생성, 구간 밖 변경, 자동 게시, 승인 없는 실제 생성. 비용 한도와 재시도 상한의 수치 확정도 현재 자료만으로 하지 않음.
- 현재 실행 허용: 문서와 수동 흐름 검토. 전체 개발과 실제 고객 자료의 모델 전송은 허용하지 않음.

## 품질 기준

| ID | 조건과 이유 | 확인 방법 | 판정과 행동 |
|---|---|---|---|
| Q1 | 원본 보존. INPUT-01의 원본 손실 금지 조건 | 원본과 후보를 별도 대상으로 두고 대조. 실제 구현 후 원본 유지 확인 필요 | 원본 유지면 충족, 덮어쓰기 가능성이 있으면 중단하고 원본 유지 경로로 복구 |
| Q2 | 작업자가 선택한 한 구간만 변경. INPUT-01의 범위 조건 | 선택 시작과 끝, 변경 대상 비교. 실제 출력 비교는 생성 승인 후 | 범위가 명확해야 진행, 구간 밖 변경 가능성이 있으면 후보 반려와 수동 검토 |
| Q3 | 단가, 재시도 상한, 승인 확인 전 실제 생성 보류 | 프로젝트 담당자가 공급자 단가와 비용 한도, 재시도 상한 수치, 자료 전송 권한과 생성 승인을 확인 | 하나라도 미확인이면 생성 보류, 문서와 수동 검토만 진행 |

Q1과 Q2의 실제 출력 시험은 아직 없다. 계획이 존재한다는 이유로 품질 합격을 기록하지 않는다. 처리와 복구는 architecture.md에서 같은 Q-ID를 참조한다.

## 운영 지속 조건

- 가치 단위: 작업자가 채택할 수 있는 구간 수정 결과. 실제 채택과 지불 의향 미확인.
- 사용과 원가 단위: 구간 길이, 언어, 생성과 재시도, 사람 검토와 지원.
- 단가, 사용량, 비용 상한, 재시도 상한 수치: 모두 미확인.
- 실제 구매 또는 도입 근거: 없음. INPUT-01은 고객 증거가 아님.
- 승인 담당: 프로젝트 담당자가 권한 있는 승인자와 한도를 확인하고 progress.md에 새 결정을 남긴 뒤 실제 생성 범위를 확정한다.
- 첫 리뷰: progress.md의 DEC-001, 2026-11-17. 유지, 수정, 축소, 중단/보류, 추가 관찰 조건을 확인한다.
