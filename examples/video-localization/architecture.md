# 영상 현지화, 처리 구조와 책임

실제 회사 기록과 별개의 연습 설계입니다. 코드는 구현되지 않았고 실제 시험 결과도 없습니다. 품질 기준은 prd.md의 Q1, Q2, Q3를 참조하며 이 파일에서 바꾸지 않습니다.

## 입력과 출력

- 결정: progress.md의 DEC-001
- 입력: customer.md의 INPUT-01, 작업자가 정할 구간 시작과 끝, 수정 이유. 실제 영상과 음성의 모델 전송 권한은 미확인.
- 지금 받을 출력: 선택 구간, 원본 보존, 후보 채택과 반려를 설명한 수동 흐름.
- 나중에 허용될 수 있는 출력: 사람이 검토할 해당 구간 후보. Q3를 충족하고 새 결정으로 승인하기 전 생성하지 않음.

## 처리와 HITL

| 순서 | 담당과 처리 | 기준 | 사람의 확정 |
|---|---|---|---|
| 1 | 편집자가 한 구간의 시작과 끝, 수정 이유 선택 | Q2 | 선택 범위와 자료 사용 권한 확인 |
| 2 | domain 규칙이 구간 범위, 원본 분리, 승인과 한도 확인 | Q1, Q2, Q3 | 미확인 항목은 프로젝트 담당자에게 돌림 |
| 3 | adapters의 모델 연결이 허용 구간의 후보 생성 | Q3 | 현재는 보류. 권한 있는 승인자가 비용, 상한, 전송을 확정해야 진행 |
| 4 | 편집자가 원본과 후보를 비교 | Q1, Q2 | 채택, 반려, 보류를 선택하는 HITL. 구간 밖 변경이면 반려 |
| 5 | 채택 후보를 별도 결과로 보관하는 흐름 | Q1, Q2 | 자동 게시 없음. 외부 전달은 별도 허용 필요 |

현재 허용 범위는 1번부터 2번까지의 수동 검토와 4번의 채택 절차 검토다. 실제 생성, 저장 동작과 게시를 실행한 상태가 아니다. 모델이 권한과 한도를 추론하거나 재시도를 스스로 늘리지 않는다.

## 개발 폴더 책임 예

| 위치 | 맡을 책임 | 상태 |
|---|---|---|
| 루트 customer.md, prd.md, architecture.md, progress.md | 자료, 기준, 처리, 결정 누적 | 채운 연습 문서 |
| src/domain/ | 구간, 원본, 권한, 비용과 재시도 상한의 결정적 규칙 | 폴더 설계, 코드 미구현 |
| src/adapters/ | 허용된 모델 연결과 응답 처리 | 폴더 설계, 연결 보류 |
| tests/fixtures/ | 권한 있는 시험 입력과 기대 경계 | 폴더 설계, 실제 시험 없음 |

HITL은 위 처리의 승인과 채택 지점에 있다. 별도 폴더를 만들었다는 이유로 사람 검토가 이루어지지 않는다.

## 오류와 복구

| 상황 | 즉시 행동 | 복구와 책임 |
|---|---|---|
| 단가, 한도, 권한 또는 재시도 상한 미확인 | Q3에 따라 실제 생성 보류 | 프로젝트 담당자가 승인자와 확인, 수동 검토 유지 |
| 구간 선택이 모호하거나 구간 밖 변경 가능 | Q2에 따라 진행 중단 또는 후보 반려 | 편집자가 범위를 다시 선택, 기존 원본 유지 |
| 생성 실패, 비용이나 재시도 한도 도달 | 추가 생성 중단, 오류와 실제 사용 기록 | 프로젝트 담당자 재검토. 자동 재시작 없이 수동 대안 검토 |
| 원본 덮어쓰기 위험 | Q1에 따라 후보 채택 중단 | 원본 분리 확인, 편집자가 기존 상태로 돌아감 |

## 가장 작은 확인

INPUT-01로 선택 구간부터 사람의 채택까지 수동으로 따라가며, 원본과 후보, 허용 범위를 구별할 수 있는지 본다. 프로젝트 담당자가 2026-11-17에 실제 한 일과 못 한 일을 progress.md에 새 리뷰로 남긴다. 이 계획은 음질, 길이 개선이나 고객 수요를 확인한 결과가 아니다.
